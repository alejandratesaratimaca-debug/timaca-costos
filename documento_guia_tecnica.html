A. Stack Tecnológico Principal

Node.js v20.18+ LTS Entorno de ejecución de backend/local. Ejecuta scripts de lectura masiva de Excel, procesamiento de datos y compilación del sistema.
Vercel Nube CDN Infraestructura de Alojamiento y Despliegue Continuo. Servidores cloud globales que sirven la aplicación en vivo con certificado de seguridad SSL en timaca-costos.vercel.app.

C. Comandos Esenciales de Terminal para el Equipo

Para trabajar en la aplicación desde Visual Studio Code o terminal PowerShell, se utilizan 3 comandos clave:

1. Iniciar el entorno de desarrollo local (en la computadora):

npm run dev

Inicia un servidor local en http://localhost:3000. Cualquier cambio guardado en un archivo se actualiza en el navegador de manera inmediata sin recargar la página.

2. Verificar compilación y detectar posibles errores:

npm run build

Compila todo el proyecto con Vite y valida que no existan errores de sintaxis, variables sin definir o tipos incompatibles.

3. Publicar cambios a producción en la nube (Vercel):

npx vercel --prod

Sube los archivos y emite la nueva versión a https://timaca-costos.vercel.app/ visible para toda la empresa en segundos.

Recomendación para adecuaciones: Antes de desplegar a producción con npx vercel --prod, siempre ejecute npm run build para comprobar que el código se compila limpiamente al 100%.
